# 🎓 Student Management App

A full-stack **Spring Boot** application for managing student details, marks, and results.  
This project demonstrates CRUD operations, RESTful APIs, and MySQL database integration .

---

## 🚀 Features
- Add, update, view, and delete student records  
- Manage marks and calculate total and grade  
- REST API endpoints for all operations  
- Integrated with MySQL database using Spring Data JPA  
- Layered architecture (Controller, Service, Repository)  

---

## 🛠️ Tech Stack
- **Backend:** Java, Spring Boot, Spring MVC, JPA/Hibernate  
- **Database:** MySQL  
- **Build Tool:** Maven  
- **IDE:**  Eclipse
